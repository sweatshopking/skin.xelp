[B]1.0.4[/B]
- New: picture screensaver drawn by the skin itself (works on Windows, where Kodi's add-on screensaver fails). Set the skin string IdleSlideshowPath to a folder of pictures; it appears after 2 minutes without input, or when System > Screensaver is chosen, and any input hides it.

[B]1.0.3[/B]
- Default main menu: Home is the first entry (you land on it), and Search sits just above System.

[B]1.0.2[/B]
- The mouse pointer is now a small amber dot instead of fTV's "WARNING! Mouse not supported please disable" banner, which appeared on screen at start-up whenever a controller registered as a mouse.

[B]1.0.1[/B]
- Start-up screen now shows the xelp splash instead of the old fTV logo.
- Games on the Home page (when Games is highlighted in the menu) is a wrapped poster grid instead of one row.
- Main menu: the old "Exit" entry is now "System" and holds Settings, Reboot, Power off and the rest; the separate Settings entry is gone from the default menu.

[B]1.0.0[/B]
- First release of xelp, a fork of the fTV skin by Hitcher.
- New Poster Grid view for movies, TV shows, seasons and games (title and year under every poster).
- Home pages rebuilt as real rows: heading above each row, titled posters, scroll up/down between rows and sideways inside a row.
- Dimmed backdrop art of the selected title behind the home rows; clock and greeting on the Home page.
- Continue Watching opens the next episode; context-menu hint ("Press X for options").
- Film page opens on the play button (Watch Now / Resume) instead of the Overview tab.
- Rotten Tomatoes audience score shown when the library has it.
- Titles with no artwork show their name on the card instead of a blank tile.
- Fixed: view switching removed (the grid is the only view for those lists); several focus and click bugs of the old home rows.
